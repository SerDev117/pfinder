this program "pfinder" was made to help developers find their project scattered across multiple folders 
the program has a small selection of commands:
help
version


find + --language + your language
--
for now it supports only these languages:
java
cpp/c++
javascript
python
rust

im planning to add a couple more languages in the future 

the project is entirily made in rust and probably will remain in it unless i make a version with ui
